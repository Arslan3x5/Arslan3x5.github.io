Sales Insights

Upload a sales CSV and get cleaned data, KPIs, customer segments and a next-month forecast with its error shown.

Every removed row is counted on the page, and the forecast method is chosen by testing four options on recent months. The live demo uses synthetic data.

TaskFlow

A kanban task manager with accounts, drag and drop, live stats and a REST API.

Each user sees only their own tasks, 12 automated tests run on every push, and the app is deployed with a PostgreSQL database.

HF Trend Tracker

A daily history of what is trending on Hugging Face, so you can see what is rising, not just what is big.

A scheduled job snapshots the top 300 models, datasets and Spaces every day and publishes an open dataset. A dashboard shows the fastest risers and new entrants, and an MCP server lets AI agents ask for trends.

AskMyDocs

Ask questions about your own PDFs on your own server. No AI service, and no data leaving the machine.

Answers show the exact sentence with its file and page, and it says "Not found" instead of guessing. An accuracy page scores your own test questions, and offline mode blocks outgoing connections.
